# MikeDenman.online Cloudflare V2

Static, mobile-first portfolio for Cloudflare Pages.

No framework and no build step are required.

Files:
- index.html
- styles.css
- app.js
- sky.js
- data/projects.json
- _headers

Portfolio cards live in data/projects.json.

Recommended deployment: GitHub connected to Cloudflare Pages, so every GitHub update automatically redeploys the site.
