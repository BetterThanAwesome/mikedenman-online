MIKE DENMAN ONLINE
Static Cloudflare Pages package

UPLOAD
1. Unzip this package.
2. In Cloudflare, open Workers & Pages, then your Pages project.
3. Use Create deployment or Direct Upload.
4. Upload the CONTENTS of this folder, with index.html at the root.
5. After deployment, point MikeDenman.Online to the Pages project in Custom Domains.

EDIT LINKS
Open site-config.js. All main external URLs are in one place.

EDIT COPY
Open index.html. Every visible section is plain HTML.

EDIT IMAGES
Replace files in assets while keeping the same filenames, or change the image source in index.html.

NO BUILD STEP
This site is plain HTML, CSS, and JavaScript. No npm, framework, or build command is required.
